# Bava's Restaurant — SEO-optimised website

Static site (HTML/CSS, no build step). Deploy by uploading this folder to GitHub Pages, Netlify or Vercel.

## After deploying
1. Find-and-replace `https://YOUR-USERNAME.github.io/bavas-restaurant` with your live URL in every `index.html`, `robots.txt` and `sitemap.xml`.
2. Replace `+91XXXXXXXXXX` / `91XXXXXXXXXX` with the restaurant's real phone number (tel: and WhatsApp links).
3. Fill the yellow-highlighted address and hours in `contact/index.html` and the footer (search for `class="todo"`), and in the JSON-LD `address` block.
4. Submit `sitemap.xml` in Google Search Console.
